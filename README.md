## Microsoft + Esri field enablement

A curated front door for Esri subsidiaries, distributors, partners, sellers,
solution engineers, and Microsoft field teams exploring Microsoft + Esri integrations.

Use this repository to connect a customer need with a relevant integration,
learning resource, and next conversation. It complements, rather than replaces,
Microsoft Learn and Esri product documentation.

## Follow the customer journey

Customer Scenario -> Relevant Integration -> Demo -> Architecture -> Official Documentation

1. Start with the [Government scenario](03-scenarios/government.md) and
   [customer discovery questions](01-start-here/customer-discovery-questions.md).
2. Identify a candidate in the [integration catalog](02-integration-catalog/README.md).
3. Check [demo resources](04-demos/README.md) for a suitable learning path.
4. Review [architecture guidance](05-architecture/README.md) and unresolved requirements.
5. Confirm technical details in [Microsoft resources](07-resources/microsoft-resources.md)

## How to read this guidance

* Official documentation is the authority for product behavior, prerequisites,
  limitations, licensing, availability, and support.
* Curated field guidance consists of suggested questions, candidate use cases,
  and evaluation steps. It is not a product guarantee or an endorsement by
  Microsoft or Esri.
* "Source to be validated" means evidence is pending. Do not present the item
  as a verified capability or use it as a customer commitment.

The initial catalog contains one source-backed integration, not an exhaustive
inventory. No repository-owned demos or validated architectures are included yet.
Source review dates record a documentation check, not a tested deployment.
