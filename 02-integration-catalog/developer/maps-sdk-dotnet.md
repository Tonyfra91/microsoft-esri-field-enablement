## In one sentence

ArcGIS Maps SDK for .NET is a developer starting point for building mapping
experiences into custom .NET applications.

## Why a customer cares

* Shape an application around a specific user task
* Consider geographic context within a purpose-built workflow
* Evaluate whether custom development is justified over an existing app

## Listen for this

> "Our users need a dedicated application."

## Questions to ask

* What must a user do that existing applications do not support?
* Which devices, data, and access conditions matter?
* Who owns development, maintenance, and support?
