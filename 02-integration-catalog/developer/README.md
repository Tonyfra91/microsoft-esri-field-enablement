## When a standard experience is not enough

A customer may need a purpose-built application for a particular role or
workflow. First ask what users must do that the existing applications do not
address. Custom development introduces delivery and maintenance responsibilities.

The initial starting page is
[ArcGIS Maps SDK for .NET](maps-sdk-dotnet.md).
Bring a developer and an Esri solution engineer into the next conversation.

## Keep the boundaries clear

The SDK is a development tool, not a ready-made Microsoft 365 integration.
Platform support, authentication, distribution, licensing, and the proposed
application architecture require current product validation.
AI, agents, and MCP patterns are not included in this first pass.
