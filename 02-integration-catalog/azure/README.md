## Start with what the GIS must deliver

For customers using Azure, the conversation is about the people and operations
the GIS supports: dependable access, capacity, recovery, and ownership.
It is not the same conversation as embedding maps in Microsoft 365.

| Customer signal                                   | Discovery topic                                              |
| ------------------------------------------------- | ------------------------------------------------------------ |
| "Our enterprise GIS strategy involves Azure."     | [ArcGIS Enterprise on Microsoft Azure](arcgis-enterprise.md) |
| "Our GIS specialists need cloud-based computing." | [ArcGIS Pro on Microsoft Azure](arcgis-pro.md)               |

## Validate before designing

These pages are discovery placeholders, not supported configurations or
reference architectures. Version-specific Azure deployment guidance, supported
infrastructure, licensing, costs, and government-cloud availability:
**Needs current-source validation**.

Bring the GIS administrator, Azure owner, and an Esri solution engineer into
the discussion before recommending infrastructure. Do not use a generic cloud
diagram as proof of ArcGIS support.
