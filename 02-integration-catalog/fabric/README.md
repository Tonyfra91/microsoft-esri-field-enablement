## Bring location into the data conversation

When customers bring enterprise data together, ask where location changes the
analysis. ArcGIS for Microsoft Fabric provides mapping and spatial analytics
starting points; Power BI connects the conversation to business reporting.

## Choose the question first

| Customer question                                                    | Starting point                                              | Conversation focus             |
| -------------------------------------------------------------------- | ----------------------------------------------------------- | ------------------------------ |
| "How can we analyze geographic relationships across large datasets?" | [ArcGIS GeoAnalytics for Microsoft Fabric](geoanalytics.md) | Spatial analytics              |
| "What would a map reveal about our Fabric data?"                     | [ArcGIS Maps for Microsoft Fabric](maps-for-fabric.md)      | Mapping and geographic context |
| "How does performance vary by place?"                                | [ArcGIS for Power BI](power-bi.md)                          | Reports and dashboards         |

These are different experiences, not interchangeable names. Listing Power BI
here does not require the customer to adopt Maps or GeoAnalytics.
Start with the decision, then involve the data platform and GIS owners.
